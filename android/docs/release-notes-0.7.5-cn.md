# Ava 0.7.5 - 7

标签是一周。第 7 个主题。

0.7.4 让 2018 年的硬件跑得动今天的 Home Assistant。0.7.5 把同一周里的几件事收在一起：新设备可以继承旧设备的配置，唤醒词开始适应当前房间，没有合适唤醒词或只有遥控器的设备也能继续用，播报音量可以按环境噪音自动抬高。

夜里到早上又补了几处。多台墙上的 NSPanel 不再把同一只蓝牙传感器在房间之间来回抢走；Android 12 以下侧边栏用假模糊跟上液态玻璃滑条；设备服务头部的重启退出和异常结束收成并排两格。感谢 @open-forest 在 [#211](https://github.com/knoop7/Ava/issues/211) 里把互抢写清楚。

## 新设备可用配对码继承旧设备配置

家里再加一台平板，不必把语音、浏览器、模组和小组件再配一遍。两台 Ava 在同一局域网内即可直传：发送端显示 6 位配对码，接收端输入后开始传输。窗口开放 5 分钟，全程加密，不经过云，也不需要 U 盘。

可勾选界面与服务、浏览器、语音、音乐、模组、启动器图标和小组件布局。Home Assistant、Music Assistant 凭据默认不发送；MAC 与 ESPHome 节点名始终留在原机，接收方在 Home Assistant 中仍是独立设备。接收完成后需用户确认才会应用。首次安装的引导页不会弹出配对，需在备份与恢复中手动进入发送或接收。

路径：**Ava 设置 -> 备份与恢复 -> 克隆**

## 唤醒词在本机学习，减少路过误触发

走廊路过、电视对白，容易把墙上的平板喊醒。这一周加入设备端自学习：成功进入对话的唤醒作为正样本，没有识别到文字或很快被取消的作为负样本。样本只保存在本机，不上传录音。

新校验器不会立刻替换出厂判断。交叉验证通过后才会发布：真唤醒至少保留 90%，误唤醒拦截不能变差。样本不足时继续使用出厂校验器。Open Wake Word 与 microWakeWord 共用这一层；Open 的 embedding 改为设备端 C++，不再走 ONNX。设置页可查看学习状态，也可重训或清空。

路径：**Ava 设置 -> 语音配置 -> 唤醒学习**

## 不喊唤醒词，也可用悬浮按钮开始说话

手上不方便说话时，不必再喊唤醒词。屏幕左右边缘提供可拖动的悬浮麦克风，默认收成 D 形把手，拉出后变为圆钮。三种方式：

- **语音**：继续使用唤醒词，不显示按钮
- **按钮**：仅通过悬浮麦克风开始会话，唤醒词检测、词库和提示音同时关闭
- **混合**：唤醒词与按钮均可开始会话

点按后由 VAD 收尾；按住说话，松手即发送。会话中再次点按会中断当前 STT 或 TTS 并重新开始听。播放中的音乐会在说话时闪避。用户文本显示在按钮旁，回复使用居中三行字幕。无触摸屏、仅遥控器的设备可用方向键浏览设置，菜单键打开侧栏；触屏设备冷启动不会出现选框。

路径：**Ava 设置 -> 语音配置 -> 唤醒方式**

## 播报音量按环境噪音自动提高

夜里报天气偏响，白天环境一吵又听不见。[#209](https://github.com/knoop7/Ava/issues/209) 要求按环境噪音自动增益，且不得压低用户设定。

用麦克风空闲电平估计房间噪音，只在 TTS 滑条之上做加法。安静房间保持原值；嘈杂时最多提高约 55 个百分点，不超过满格。滑条上标出安静、正常、嘈杂、很吵四档。Home Assistant 音量实体跟随实际输出。默认关闭。

路径：**Ava 设置 -> 语音配置 -> 语音回复**

## 梦幻时钟增加满幅指针与翻页，左右滑动切换主题

墙上的平板可以一直亮着报时，不必停在原来那一种圆形机械表。梦幻时钟现在分两类：机械表盘仍是原来的圆形指针，只在设置里选择；StandBy 表盘含满幅指针和翻页时钟，悬浮窗内上下滑动切换。翻页时、分、秒各自翻牌；关掉秒后，时、分牌拉长占满。左右滑动在 52 套主题间切换，例如曜石黑、素瓷白、极光绽放，不是黑、白、彩色三档。可选 12 小时制，以及 League Gothic 或系统字体。

翻页页可开本地倒计时：5 分钟、10 分钟、25 分钟。绑定 Home Assistant `timer.*` 后才出现自定义时长。归零可响铃，点一下时钟停止。可发布 `select.dream_clock_flip_style`，在 Home Assistant 中选择一项即时应用，设备端滑动也会回写实体。可选开关远程显示或隐藏时钟。闲置后智能省电 AOD 渐入暗色遮罩；深度 85% 以内点击仍作用于时钟，超过则第一次点击只唤醒。设置按钮可长按锁定，锁定后不再出现。

路径：**Ava 设置 -> 扩展组件 -> 展示与场景 -> 梦幻时钟**

## 更新披露优先本机，其它设备放在下一步

有新版本时，披露页优先本机，提供更新和稍后。其它设备放在下一步，避免一打开就列出全屋设备。Home Assistant 更新实体支持立即再检查，不必等待 12 小时周期。「稍后」会被记住，不会每次启动都再弹出。

路径：**Ava 设置 -> 设备服务 -> 软件更新**

## 音乐新旧协议兼容，停止词减少自触发

Music Assistant 新版本使用 Noise 握手，旧版本仍为明文 hello。两条路径并存，握手失败后三分钟内自动回退。切歌后封面、歌手和歌名同步更新。歌词按曲长过滤明显不匹配的结果。时钟校准对齐正在出声的播放时间，不再另做一套延迟模型。默认 DSP 可识别德语 "Stopp" 接近 "schtopp" / "shtop" 的发音，无需另训停止词。

TTS 起播 300 ms 内加入保护，避免播报声把自己打断。感谢 @newman1982 在 [#210](https://github.com/knoop7/Ava/issues/210) 里贴出重连被拒的日志。

## 多台面板不再互抢蓝牙已连接设备

墙上几块 NSPanel Pro 同时开着蓝牙代理时，Home Assistant 里「已连接设备」会从一间跳到另一间。[#211](https://github.com/knoop7/Ava/issues/211) 里 @open-forest 写的就是这个。

模拟插槽和局域网 UDP 认领都保留，旧设备仍能读原来的包。原先先到先得、本地认领几乎不过期；扫描休息空隙里另一台会放手再抢走。现在认领带上信号强度：本地 90 秒内不因扫描空隙放手，对端 20 秒无心跳才视为离开。要抢走须连续三次比对方强约 8 dB，且两边都已持有至少 12 秒。没有信号强度的旧包不能参与抢位。

路径：**Ava 设置 -> 蓝牙设备**

## 液态玻璃用于侧栏和悬浮窗，设置列表不加

液态玻璃用于侧边栏、悬浮窗、通知、音量和底部 dock，设置列表卡片不加玻璃。开启后侧边栏上下留白、左右离开屏幕边缘 10 dp，四角圆角，滚动边缘溶解；竖屏上下 30 dp，横屏 20 dp。强度默认 50%，滑动时可预览约 2 秒。日间保留浅描边，暗色使用黑灰。Android 12 以下没有系统背景模糊，侧边栏打开时冻一帧做假模糊，半径跟着同一条滑条走，玻璃板保持加厚，不会太透；悬浮窗仍只加厚材质，不做假模糊。关闭后梦幻时钟和浏览器不再残留模糊层。侧边栏打开时覆盖系统导航栏。悬浮小窗标题条不加玻璃。

Home Assistant 顶栏改为只内收按钮，避免整条导航出现缺口。日夜间切换在页面内完成，不整页刷新。Facebook Portal 小桌面下，应用图标不再盖住商店。Root 悬浮小窗不再以 uid 0 创建虚拟屏。横屏新安装默认左索引、右详情；竖屏保持单栏。设置页、权限管理和模组页支持遥控器焦点导航。

路径：**Ava 设置 -> 程序样式 -> 液态玻璃**

## 社区

- Android 5.1 上启动会闪退：闹钟、引导权限、Toast 和相机检查直接调用了 Android 6 才有的方法，一进前台就是 `NoSuchMethodError`。现按调用点做版本分支；5.x 安装时已授予悬浮窗和电池优化，不再打开 6.0 设置页。
- [#206](https://github.com/knoop7/Ava/issues/206)：Camera Vision 模组加入 EAN/UPC 条码识别，与 QR 并行。这是模组更新，不增加主 APK 常驻相机负载。感谢 @pantherale0 提出需求。
- [#208](https://github.com/knoop7/Ava/issues/208)：补充 Root Echo Show 的悬浮窗自动授权。长时间运行后卡住的问题仍需独立日志。感谢 @MichaelaMer 提供 Echo Show 8 与可复现步骤。
- [#209](https://github.com/knoop7/Ava/issues/209)：按环境噪音自动提升 TTS 音量。第一版仅覆盖语音回复，不改媒体和警报。感谢 @pantherale0 提出需求。
- [#210](https://github.com/knoop7/Ava/issues/210)：Sendspin 重连被服务器拒绝为 known client。感谢 @newman1982 提供日志。
- [#211](https://github.com/knoop7/Ava/issues/211)：多台 NSPanel Pro 上蓝牙已连接设备互抢。感谢 @open-forest 提供设备与复现。

感谢 @open-forest、@newman1982、@pantherale0、@MichaelaMer 在 issue 中提供设备信息、日志和复测。
