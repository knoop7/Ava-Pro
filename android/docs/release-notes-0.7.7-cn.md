## 修补版

- **开屏后显示屏保**，默认关闭。屏幕被打开时直接进入屏保，底下的页面留着。手点亮的、凑近亮的，留在那一页。在动态屏保的行为与唤醒里，接近传感器唤醒下面。感谢 @popy2k14 [#231](https://github.com/knoop7/Ava-Pro/issues/231)。
- **下拉刷新要先停住。** 手指在页面最上面停一下再往下拉，才刷新。从最上面划过去仍是翻页。
- **语音按钮可以吸在四边。** 左、右、上、下都行。冷启动时字幕两层先藏在后面，按下不再先闪一下。关掉按钮模式，这两层才收掉。
- **Android 10 的 Portal 麦克风不再被静音。** 系统已经允许自由窗口时，角落留一条碰不到的细窗。Ava 自己不去打开那个系统开关。感谢 @engfabiodario [#235](https://github.com/knoop7/Ava-Pro/issues/235)。
- **自身更新期间不再无响应。** 从 Home Assistant 给这台 Ava 装更新时，下载和等待安装改到后台，界面还能动。感谢 @popy2k14 [#233](https://github.com/knoop7/Ava-Pro/issues/233)。
- **自身更新可以静默安装。** 有 Shizuku、Root 或设备所有者时，装完不弹确认。只开了设备管理员的，仍要确认一次。感谢 @popy2k14 [#232](https://github.com/knoop7/Ava-Pro/issues/232)。
- **西班牙语。** 确定、取消、关闭仍是英文。感谢 @CarlosTohe [#234](https://github.com/knoop7/Ava-Pro/pull/234)。
- **媒体播放器实体不再循环。** 歌曲按原来的地址播放，时长和进度跟着走。在 Home Assistant 里重新连接这台设备之后生效。

# Ava 0.7.7

0.7.6 把棋子摆上了盘。这一周没有再造一套新的下法，做的是把已经说出口、却还对不上的那几步落到实处。时间是其中最清楚的一步。

说「明天定时十秒」，那是翻页时钟上的倒计时，到点就在这块屏幕上停住。说「明天早上七点叫醒我」「提醒我下午两点吃药」「后天的闹钟」，那是钟点，可以落在任何一天。「明天定时十秒」和「明天十二点」拆开走，一句里两件一起说也按这两类做完，不用再追问是哪一种。「设置」进的是 Ava 的设置。「设置闹钟」设的是闹钟。家里的安防面板仍然要先点名那台设备，没点名的钟点留在这台 Ava 上。

到点之后，屏幕上是一只闹钟。点开能改时间、换提示音、删掉这一条。正在响的时候图标转成红色，一下一下地呼吸；点一下停掉，停掉就清掉。最多二十条，满了先删一条再加。设上的才会出现在 Home Assistant 里，名字是「任务事件(闹钟)」「任务事件(提醒)」，第二条起带 -1。时间和日期双向走：Home Assistant 里改，这边跟着改；这边说一句，那边的实体就是这个钟点。空着的槽不占位置。开机之后还在。

问「还剩几分钟」，直接读当前这一只倒计时，开口就是剩下的时间。倒计时就是那块翻页的脸，回复停在「好了，还剩多少」这一句上。正在响的，说停，停的是正在响的那一只，倒计时、闹钟、提醒走同一条路。

## 问全屋，也问这台自己

「全屋有几盏灯开着」，按灯这一类去索引里数，念得出的就念，某一盏读不到就跳过这一盏，整句照样说完。「动态屏开了吗」，看的是这一页开关此刻的开和关，也能把它拨过去。模组商店不用截图：目录、已装、开着还是关着，都是文字；说装上、关掉、卸掉，就按名字做。

模型脑子里的草稿留在这一轮里，给它自己接着想。播出来的只有要说的那句。

## 屏保智能退出

自定义网址的屏保亮着时，通知场景会画在它后面，等于没看见（[#223](https://github.com/knoop7/Ava-Pro/issues/223)，感谢 @popy2k14 在 Echo Show 8 上写清楚）。现在通知叠在屏保上面。这个开关叫「屏保智能退出」，默认开着。关掉之后，通知一来，屏保按点一下屏幕的方式退出。

@popy2k14 在这条的评论里补了一句：场景把屏保打断之后，空闲计时要从头再走。关掉「屏保智能退出」时就是这样，超时从场景出现的这一下重新计。场景还盖在上面的时候，屏保不会中途再冒出来。

同一条场景连发两次，Home Assistant 的下拉认为没有变化，设备收不到第二下（[#226](https://github.com/knoop7/Ava-Pro/issues/226)，仍是 @popy2k14）。场景亮完，下拉回到 `idle`，同一条可以再选一次。以前自动化里发的 `reset` 和 `...` 仍会把当前场景收起。

开机时网络还没好，自定义场景会拉失败，这一次开机列表就是空的（[#229](https://github.com/knoop7/Ava-Pro/pull/229)，感谢 @popy2k14）。现在先用上次成功拉到的那份，再去网上重试，成功了再更新这份缓存。

麦克风那个圆钮，通知场景已经压在上面，或者程序已经收成小窗的时候，停在原处。

路径：**Ava 设置 -> 动态屏保 -> 行为与唤醒 -> 屏保智能退出**

自定义场景：**Ava 设置 -> 扩展组件 -> 展示与场景 -> 通用设置 -> 自定义场景配置**

## 梦幻时钟可以锁住

挂在墙上当钟用的时候，左右一滑就换了主题，定时器还在用。锁定之后，换主题的滑动收起来，定时器留下。满幅和翻页仍在这块时钟自己的设置里换，换的时候表盘有一段短的交叠。定时的四个按钮加高了，按下有震动。暂停那颗圆钮更大，背后的钟面暗一档。

## 触控板

三指往下收起，再来一次按同一套循环展开。录自动化的时候，键盘上打的字也记下，回放按录下来的节奏走。板面缩得很小的时候，1 到 5 还在，左右滑能看见。删一条的时候，垃圾桶是移过去的。

语音卡片里那句「关灯，放点爵士」，滚轮自己在走的时候，手指一按就停。

## 页面和层

浏览器在通知栏里的那一行，跟侧边栏、跟 Home Assistant 里的显示开关是同一件事：藏了就是藏了。点退出才收。点重载是拆掉再拉起来，免得卡死在半截。下拉刷新长在页面里面，跟方向键那种内切是同一套。

进设置时，液态玻璃从模糊过渡到清楚。好几层悬浮叠在一起时，返回留在最上一层里。这些层跟的是 Ava 自己的横竖屏。梦幻时钟盖在浏览器上面。

遥控器的焦点框，侧边栏打开时先收成透明；真的有遥控器在走，才显出来。

## 结束说话检测

静音多久算说完，现在可以选。三档和 Home Assistant 里这台卫星的「结束说话检测」是同一项，两边改是同一件事：积极 0.25 秒，默认 0.7 秒，宽松 1.25 秒。静音持续到所选时长，这一次识别结束。没接上 Home Assistant 时，这一项不出现。

路径：**Ava 设置 -> 语音配置 -> 语音转文字 -> STT 倾听引擎 -> 结束说话检测**

Android 5 和 6 上，一收到识别文字就会崩：那些系统里没有 `UnicodeScript`。现在按字本身判断，语音这条路在这些老设备上能走完。
