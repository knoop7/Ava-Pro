# Ava 0.7.4 - 梦回 2018

2018 年，这些平板被挂上墙。1 GB RAM，系统 WebView 停在 Chromium 69。那年 HA 的自定义卡片还是几行简单的 HTML。八年后，这些平板要跑 Bubble card 、玻璃拟态、UIX 、WebRTC 摄像头实时流。

0.7.4 让它们跑得动。

## 修补版

0.7.4 发布后补入当前构建。

**唤醒严格度可以再往上拉。** 引擎自己的灵敏度有上限，再拧紧也不会更准，只会听不见。现在唤醒词 1、唤醒词 2 的滑条分成两段：左边还是原来的灵敏度；拉到头再往右，进入额外确认。

- **严格+**：喊醒之后再核验一次，误报会少。Open 引擎会稍慢一点，micro 引擎不增加等待。
- **极致**：核验最严。离得远、说话轻，有可能喊不醒。

平时不必动。客厅电视、走廊路过容易误唤醒时，先试严格+。滑过档位会轻微震动；没有马达的机器不会震。Android 12 及更早的平板，以前滑条经常没震动，现在设置里其他滑条也一并接上了。

路径：**Ava 设置 -> 语音配置 -> 唤醒词**

- 设置文件损坏时先留一份备份再恢复出厂，Home Assistant 登录信息和唤醒词不会被直接抹掉。
- 系统暂时关掉「显示在其他应用上层」时，留言接收等开关不会被永久关掉；权限回来，功能还在。
- 「忽略电池优化」系统提示每个设备只问一次。服务自己重启或崩溃恢复时不会反复弹。以后仍可在引导、权限页或服务设置里手动打开。
- 后台服务反复重启时，内存不再越占越多。
- 关掉浏览器健康管家以后，页面内存过高仍会在合适时机自己刷新，老平板不会一直闪白重启。

## 系统 WebView 成为默认路径

以前跑今天的 HA 前端，重度自定义卡片渲染错位，答案永远是「装 Gecko 引擎包」：第二个进程、第二份内存、第二套权限、两次 OTA，老平板再被吃掉 200 MB。

把兼容层做进系统 WebView。语法当场降级让旧引擎解析今天的 JavaScript，缺失的 API 补齐，摄像头不再闪白，32 位内存满了自愈而非死循环。拦的是语法降级，失败回退原始字节，卡片逻辑一个字不改。Gecko 分包可以卸了，留作逃生舱，同一套兼容层也补进了 Gecko 包。省下的 200 MB 让仪表盘、语音对讲和摄像头第一次能同时跑而不掉帧。

兼容层下探到 Chromium 69。新版圆角、间距、图标尺寸，以及添加集成、添加助手一类小按钮，在旧引擎上不再崩边乱跑。弹出卡被限制在可视区内，不再冲出滚动条和 Ava 侧栏。HA 导航栏左右内收一点，不再和侧栏打架。日历卡不再被无关的实体注册表推送整卡刷白。

浏览器侧栏多了一项页面缩放：点开原地展开滑条，和 Home Assistant 的缩放实体双向同步，收起时不占地方。新手默认打开侧栏工具（油猴除外），打开浏览器就能看见。Web 控制台的输入框旁边有放大，长脚本可以全屏写完再发送。

屏外卡片停止布局绘制，屏保覆盖后 WebSocket 订阅密度自动降档，浏览器隐藏时 CSS 动画与音视频解码全部暂停。同一块 2018 年的老平板，CPU 和 GPU 负载比 0.7.3 更低，触屏响应更快。

路径：**Ava 设置 -> 屏幕与浏览器 -> 浏览器设置**

## 实验性

- **停止词引擎回声处理重写**：助手正在播报天气，说了句「stop」，没反应。机器自己的声音从扬声器回到麦克风，把人声淹没了。0.7.4 给检测器接上播放参考信号，逐频段学习回声路径增益，从麦克风信号中扣减机器贡献，在剩下的「人的证据」上做分类。TTS 播放中打断可靠。详见 Wiki。

### 贝叶斯在场融合

壁挂平板挂在那面墙上，屏幕亮着，它知道此刻有人吗？

PIR 在隔壁动一下就误报。人脸检测在暗光下失灵。单一传感器永远在误触发和漏触发之间摇摆。

 把六种观测源在设备端融合成一个占用概率：人脸、帧运动、触摸、震动、接近、声纹。融合不是投票。四层叠在一起：贝叶斯给每路信号不同的说服力，人脸几乎坐实，桌面轻震只算弱证据；蜂箱惯性让坐着不动的人不会被判离场，路过则很快清零；因果迟滞让状态不会在阈值附近来回闪；全屋先验走现有局域网身份信标，别的房间刚有人，这一间的弱信号更快被采信。

路径：**Ava 设置 -> 高级 -> 实验性**

## 修复

- **悬浮小窗全版本覆盖**：Android 7–9 走系统 freeform 模式，Android 10+ 走 scrcpy 虚拟显示镜像；镜像无法启动时自动降级到 freeform 窗口。
- Gecko 引擎包安装器优化：ROM 重写 APK 导致哈希对不上时，改用版本号确认安装完成。
- 杀进程后更新弹窗反复出现的问题修复。
- 浏览器侧栏拉手与主应用侧栏统一为 72 dp 视觉长度、36 dp 命中宽度。
- 屏保 WebView 正确继承主浏览器的字号与深色同步设置。
- 修复无 Root / Shizuku 设备上屏幕亮度回退与活动窗口遮罩的冲突。
- 桌面总服务小组件补上连接中、已断开、错误，不再只有运行和停止；音乐卡带上歌手和进度；传感器卡通过 HA 回填历史波浪线，左上角图标优先用快捷实体里存的。
- Sendspin 配对进度双向对等：手指点进度两边一起走，切歌时间轴从头对齐，取消配对后歌手和歌名不再残留。
- 开启集群网站控制台后，HA 设备页出现「访问」，点进本机 Fleet 控制台。
